# Changelog

## 1.3.1

### Added / Improved

- Bổ sung tài liệu GitHub-ready cho trang repo.
- Thêm hướng dẫn cài đặt, cấu hình, commands, placeholders và Discord Auto Buy.
- Thêm workflow GitHub Actions để build và phát hành release jar.
- Thêm issue templates, support guide và security guide.
- Đồng bộ metadata version trong `plugin.yml` từ `1.3.0` lên `1.3.1` để khớp `pom.xml` và `config.yml`.

### Compatibility

- Java 17+.
- Paper/Spigot API 1.21.x.
- Folia supported.
- PlaceholderAPI softdepend.

### Notes

Không thay đổi logic xử lý thanh toán, giao diện, database, reward, webhook hoặc Discord Store trong bản tài liệu này.
